# FaroAI

Desktop application for music-industry artist discovery and evaluation.

## Download

Latest installer (macOS `.dmg` / Windows `.exe`):

**[→ Latest release](https://github.com/farolatino-app/farolatino/releases/latest)**

Each release page includes installation instructions and SHA256 checksums.

## In-app updates

Once installed, the app pulls subsequent updates automatically through its
built-in updater (**Connections → Check for updates**). Updates are
verified by SHA256 and manifest version before applying.
